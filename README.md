## 📋 Contenido del repositorio

Este repositorio contiene las prácticas y trabajos realizados durante el curso de **Administración de Linux**, enfocados en la instalación, configuración y administración de sistemas Linux.

### 🔹 Instalación de Arch Linux
Instalación y configuración de **Arch Linux**, incluyendo particionamiento, configuración del sistema, arranque EFI y entorno gráfico.

### 🔹 Administración de almacenamiento con LVM
Configuración de **LVM (Logical Volume Manager)** y práctica de expansión de almacenamiento mediante la incorporación de un disco adicional de **5 GB** al directorio `/home`.

### 🔹 Script de monitoreo y administración
Desarrollo de un **script Bash** para automatizar tareas de administración y monitoreo del sistema Linux.
